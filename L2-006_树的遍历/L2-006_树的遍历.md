# L2-006 - 树的遍历（25 分）

- **时间限制**: 400 ms
- **内存限制**: 65536 KB
- **代码长度限制**: 16 KB

---

## 题目描述


给定一棵二叉树的后序遍历和中序遍历，请你输出其层序遍历的序列。这里假设键值都是互不相等的正整数。

### 输入格式:

输入第一行给出一个正整数$$N$$（$$\le 30$$），是二叉树中结点的个数。第二行给出其后序遍历序列。第三行给出其中序遍历序列。数字间以空格分隔。

### 输出格式:

在一行中输出该树的层序遍历的序列。数字间以1个空格分隔，行首尾不得有多余空格。

### 输入样例:
```in
7
2 3 1 5 7 6 4
1 2 3 4 5 6 7
```

### 输出样例:
```out
4 1 6 3 5 7 2
```

### 代码实现

完整实现位于同目录的 [main.rb](./main.rb)，以下代码与该入口文件保持一致。

```ruby
# frozen_string_literal: true
require_relative '../gplt_runtime'
def entry
  v = (py_map(->(x) { py_int(x) }, py_tokens).to_a)
  n = v[0]
  post = py_slice(v, 1, (1 + n), nil)
  ino = py_slice(v, (1 + n), (1 + (2 * n)), nil)
  pos = Hash[py_iterable(py_enumerate(ino)).flat_map { |__item_0|; i, x = __item_0; [[x, i]] }]
  build = lambda do |pl, pr, il, ir|
    if ((pl >= pr))
      return nil
    end
    root = post[(pr - 1)]
    z = pos[root]
    left = build.call(pl, ((pl + z) - il), il, z)
    right = build.call(((pl + z) - il), (pr - 1), (z + 1), ir)
    return [root, left, right]
  end
  root = build.call(0, n, 0, n)
  q = [root]
  out = []
  while py_truth(q)
    x, l, r = q.delete_at(0)
    out.append(x)
    if py_truth(l)
      q.append(l)
    end
    if py_truth(r)
      q.append(r)
    end
  end
  py_print(py_map(->(x) { py_str(x) }, out).join(" "), sep: " ", ending: "\n")
end
entry
```
